# Rolo Forever

Eén pagina voor Roy & Louise: een teller die laat zien hoe lang ze al samen zijn, sinds 12 augustus 2013, 20:00 (Nederlandse tijd).

- `index.html` is de hele pagina (geen build nodig).
- `foto.jpg` is de achtergrondfoto.
- Het project staat op Vercel en wordt bij elke wijziging op `main` automatisch opnieuw gepubliceerd.
